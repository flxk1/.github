# .github

Default community health files for the `flxk1` account. GitHub serves every
file here to any public repository of this account that does not carry its own
copy.

- `contributing.md` — how to suggest an improvement. No code contributions are
  accepted; proposals go to `contributions@felixkrone.de` in prose.
- `code-of-conduct.md` — Contributor Covenant v2.1, contact
  `conduct@felixkrone.de`.
- `SECURITY.md` — private disclosure, scope, timelines, safe harbour. Contact
  `security@felixkrone.de`.
- `.github/ISSUE_TEMPLATE/` — bug form only; `config.yml` disables blank issues
  and routes proposals and questions to email.

Workflows are not served account-wide. `close-external-prs.yml` lives in each
repository that has pull requests enabled.

A repository's own copy of any of these files takes precedence over the copy
here.
