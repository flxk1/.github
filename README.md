# .github

Default community health files for the `flxk1` account. GitHub serves every file
here to any public repository of this account that does not carry its own copy.

- `contributing.md` — how to suggest an improvement. No code contributions are
  accepted; proposals are issues, in prose.
- `code-of-conduct.md` — Contributor Covenant v2.1, adapted for a project with
  a single maintainer.
- `SECURITY.md` — private disclosure through each repository's Security tab,
  with the scope, timelines and safe harbour.
- `.github/ISSUE_TEMPLATE/` — a bug form and a proposal form, with blank issues
  disabled.

There is no contact address anywhere in this repository, and that is deliberate.
Every channel is one GitHub already provides and already authenticates: the
Security tab for vulnerabilities, issues for everything else. A mailbox beside
them would mostly collect spam.

Workflows are not served account-wide. `close-external-prs.yml` lives in each
repository that has pull requests enabled.

A repository's own copy of any of these files takes precedence over the copy
here.
